* sendAll directly reads the constructor instance’s separate empty address Map. Static load/update methods populate the class Map, so the instance reports no balances. The instance is receiver state, not a second balance authority. No admitted external mutation fills its Map.

Its real tallyMap factory starts before the debit factory; the first read is resumed at that factory and its cache lookup completes after the debit load.
